# AI-Gate — комплаенс-шлюз для безопасного использования LLM

**Для CISO, DPO и служб комплаенса банков и госсектора РК**

---

## Проблема

Ваши сотрудники **уже** отправляют данные в ChatGPT, Claude и Gemini:
договоры, клиентские базы, исходный код, API-ключи. По отраслевым данным,
~40% обращений к ИИ-инструментам содержат чувствительные данные.

Для организации в Казахстане каждый такой случай — это:

- **трансграничная передача ПДн** (ст. 16 Закона № 94-V) поверх обязанности
  хранить первичную базу ПДн в РК (ст. 12);
- штраф по ст. 79 КоАП — до **2000 МРП (≈ 8,65 млн тг)** и риск блокировки;
- утечка коммерческой тайны и секретов, которую не вернуть.

**Запретить LLM не получится** — сотрудники продолжат с личных устройств.
Продуктивность, которую даёт ИИ, терять тоже нельзя.

## Решение

AI-Gate встаёт между сотрудниками и LLM по **всем каналам** и делает
использование ИИ легальным:

| | |
|---|---|
| **Детект** | ИИН/БИН по контрольной сумме РК, ФИО (включая казахские форматы), счета IBAN/карты, API-ключи и секреты, суммы, маркеры коммерческой тайны |
| **Обратимая маскировка** | наружу уходит «Клиент [PERSON_1], ИИН [IIN_1]» — сотрудник получает осмысленный ответ с восстановленными данными, а не [ЗАМАЗАНО] |
| **Каналы** | браузер (ChatGPT/Claude/Gemini), корпоративные приложения и RAG (egress-proxy), рабочие станции (буфер обмена, Cursor/Claude Desktop), IDE, 1С |
| **Аудит** | неизменяемый журнал с криптографической цепочкой — отчёт для регулятора без раскрытия самих данных |
| **Политики** | маскировать / блокировать / разрешить — по типу данных, отделу, каналу; секреты блокируются по умолчанию |

## Почему AI-Gate, а не глобальный DLP

- **On-prem в вашем периметре**: данные и журналы не покидают РК —
  Nightfall, Microsoft Purview и Zscaler этого не дают;
- **казахстанская специфика**: валидация ИИН/БИН по официальному алгоритму,
  казахские ФИО, IBAN KZ, политики на русском;
- **fail-closed**: при любой ошибке запрос блокируется, а не «проскакивает»;
- **работает в закрытом контуре**: ядро без внешних зависимостей, поддержка
  локальных LLM (данные могут вообще не покидать периметр);
- локальная поддержка и внедрение.

## Как попробовать

**Пилот за 2–3 месяца**: один департамент, один канал, ваш стенд.
Разворачивается за один день (Docker). Критерии успеха фиксируем на старте:
точность по ИИН/БИН, отчёт «N запросов, M маскирований, K блокировок,
0 утечек в открытом виде».

## Модель лицензирования

- **Per-seat** — браузерное расширение и агент рабочих станций;
- **Enterprise on-prem** — egress-канал, интеграции (1С, API), поддержка;
- внедрение и обучение — по объёму.

*Точные условия — по итогам скоупинга; пилот — на льготных условиях.*
