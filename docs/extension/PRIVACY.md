# Политика конфиденциальности расширения AI-Gate DLP

Действует с версии 0.3.0.

## Что делает расширение

Перед отправкой сообщения в ChatGPT, Claude или Gemini расширение передаёт текст сообщения на **шлюз AI-Gate**. Шлюз заменяет персональные данные метками вроде `[PERSON_1]`, и на сайт ИИ уходит уже обезличенный текст. Когда приходит ответ, расширение просит шлюз расшифровать метки и показывает настоящие значения в собственной панели. В страницу сайта они не вписываются: сайт видит только метки и не может сохранить значения.

## Куда уходят данные

- **Текст сообщений** уходит только на шлюз, адрес которого указали вы или администратор вашей организации. По умолчанию это `http://localhost:8080`, то есть ваш собственный компьютер.
- **Разработчику расширения** не передаётся ничего: ни тексты, ни настройки, ни статистика использования.
- **Сайт ИИ** (ChatGPT, Claude, Gemini) получает только обезличенный текст.

## Что хранится на устройстве

| Что | Где | Сколько |
|---|---|---|
| Адрес шлюза, ключ канала, имя пользователя для журнала | `storage.local` браузера, без синхронизации с аккаунтом | пока вы их не удалите |
| Идентификаторы сессий шлюза для открытых диалогов | `storage.session`, только в памяти | до закрытия браузера |

Настоящие значения персональных данных расширение не хранит. Они живут в памяти шлюза в зашифрованном виде и удаляются по истечении срока.

## Разрешения и зачем они нужны

| Разрешение | Зачем |
|---|---|
| `storage` | хранить адрес шлюза и ключ канала |
| доступ к `localhost` | обращаться к шлюзу на вашем компьютере |
| доступ к другому адресу шлюза (запрашивается отдельно) | если шлюз установлен на сервере организации; разрешение запрашивается только для указанного адреса |
| работа на chatgpt.com, chat.openai.com, claude.ai, gemini.google.com | перехватить сообщение до отправки и восстановить значения в ответе |

Расширение не загружает код из сети, не показывает рекламу и не использует аналитику.

## Управление организацией

Администратор может задать адрес шлюза и ключ канала политикой браузера (GPO, MDM). В этом случае пользователь видит эти поля в настройках, но не может их изменить.
